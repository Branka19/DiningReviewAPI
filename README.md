# DiningReview API

- base for this project is the CodeCademy portfolio project for the skill path **Create REST APIs with Spring and Java**
- I used **React.js** to create the frontend for this project, more information here: [link]

## Project Description:
+ the application should allow registered users to add reviews for restaurants
+ the restaurants can be searched based on food allergies, location and overall score
+ an administrator validates restaurants, approves/rejects pending reviews from users and can view all users

> [!NOTE]
> This project is still work in progress and was created for learning purposes.
